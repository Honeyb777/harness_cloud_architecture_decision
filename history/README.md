# History

History는 상세 작업일지가 아니라 누적 Architecture 변경의 요약 증적이다.

권장 기본값은 월 단위다.

예:

`2026-09.md`

형식:

## YYYY-MM

### <Project / Service>
- 결정: ...
- 변경: ...
- 주요 이유: ...
- Risk/Exception: ...
- Ref: DEC-YYYY-NNN

## 저장 위치

개별 검토 이력은 `assessments/<assessment>/history/`에 보관한다.
이 디렉터리는 하네스 자체 변경과 여러 검토에 걸친 요약을 관리하며, 상세 기록은 원본 링크로 연결한다.
