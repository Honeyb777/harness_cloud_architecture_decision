# 역할 목록

모든 역할은 검토 건별로 필요한 경우에 사용하며, 사용 후 [평가 정책](../sot/AGENT-LIFECYCLE.md)을 따른다.

| 역할 | 주요 범위 / 선택 조건 | 상태 |
|---|---|---|
| [Orchestrator](00-orchestrator.md) | 범위, Step, 역할 선택·조정·평가 후속 조치 | ACTIVE |
| [Cloud Architect](10-cloud-architect.md) | Cloud/IDC 배치와 전체 아키텍처 통합 | ACTIVE |
| [Platform / Kubernetes](20-platform-kubernetes.md) | 실행 플랫폼 및 Kubernetes 필요성 | ACTIVE |
| [DevOps / Application Delivery](25-devops-application-delivery.md) | Java·Kotlin/Tomcat, Vue/npm 등 빌드·런타임·CI/CD | ACTIVE |
| [Security / Identity / Audit](30-security-identity-audit.md) | 인증, 권한, 보안, 감사 | ACTIVE |
| [Network / Hybrid Connectivity](35-network-hybrid-connectivity.md) | 네트워크, 기존 IDC 및 Hybrid 연동 | ACTIVE |
| [FinOps](40-finops.md) | 비용·태그·회선·도구 및 운영비 | ACTIVE |
| [Data / Storage](50-data-storage.md) | DB, 저장소, 데이터 이전·복제·복구 | ACTIVE |
| [Reliability / Operations](60-reliability-operations.md) | 가용성, DR, 배포 후 운영과 장애 대응 | ACTIVE |
| [Alternatives / Research](70-alternative-researcher.md) | 대안과 최신 공식 근거 확인 | ACTIVE |
| [Reviewer](80-reviewer.md) | 결과 검증, 공백·중복·역할 적합성 평가 | ACTIVE |
| [Historian / Reporter](90-historian-reporter.md) | 검토 건별 결정·평가·보고서·이력 및 전역 색인 | ACTIVE |

ACTIVE는 선택 가능한 역할이라는 뜻이며 매번 모두 실행하거나 성능 검증이 끝났다는 의미는 아니다.
